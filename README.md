# Qulogi

[Русский](README.md) | [English](README.en.md)

Qulogi — кроссплатформенный инструмент для свободного доступа в интернет при активной фильтрации трафика. Два способа обхода в одном ядре: обфусцированный туннель до собственного сервера и локальный DPI-обход на уровне TLS. Ядро написано на Go, интерфейс — Flutter с Material 3 Expressive. Никаких чужих серверов посередине: трафик идёт только через то, что настроили вы.

Статус: ядро и консольные клиенты полностью рабочие, десктопный путь закрыт. Интеграция Android через VpnService — следующий шаг (см. дорожную карту).

## Как это работает

Приложение или консольный клиент поднимает на устройстве локальный SOCKS5-прокси и ведёт трафик одним из двух способов:

- **Туннель.** Весь трафик уходит в зашифрованном туннеле на ваш сервер и выходит в интернет уже с него. Для инспекции это нечитаемый поток случайных байтов между вами и вашим сервером.
- **DPI.** Трафик идёт напрямую, но TLS ClientHello разбивается на сегменты так, чтобы инспекция не увидела имя хоста в первом пакете. Сервер не нужен.

```text
приложение (Flutter)
      |
      v
локальный SOCKS5 -- qulogi (Go)
      |
      +-- режим DPI ----> разрыв ClientHello после SNI ---> напрямую в интернет
      |
      +-- режим туннель -> AES-256-GCM поверх TCP -----> qulogid (VPS) ---> интернет
```

## Что внутри

- `internal/tunnel` — протокол туннеля: рукопожатие со свежими солениями, HKDF-SHA256, AES-256-GCM, кадры со счётчиком. Неверный ключ отбрасывается на первом же кадре.
- `internal/socks5` — локальный SOCKS5-сервер с подключаемым «насосом» трафика.
- `internal/dpi` — разбор ClientHello и разрыв после SNI, либо вручную: 1, 8 или 32 байта.
- `internal/engine` — режимы вместе, счётчики трафика, статус.
- `cmd/qulogi` — клиентская консоль, `cmd/qulogid` — серверная.
- `mobile` — биндинги gomobile для приложения на Android.
- `app` — Flutter-клиент: динамический цвет, экран соединения, настройки, журнал.

## Быстрый старт

### Сервер

На любой VPS с Linux:

```bash
go install github.com/mel0k1/qulogi/cmd/qulogid@latest
qulogid -listen :443 -psk ДЛИННЫЙ_СЛУЧАЙНЫЙ_КЛЮЧ
```

Откройте выбранный порт (TCP) в брандмауэре. PSK — единственная защита входа, делайте его длинным и храните как пароль.

### Клиент

```bash
go install github.com/mel0k1/qulogi/cmd/qulogi@latest
qulogi -server example.com:443 -psk ТОТ_ЖЕ_КЛЮЧ
```

На `127.0.0.1:1080` появится SOCKS5. Направьте туда браузер или нужное приложение — трафик пойдёт через сервер.

Без `-server` клиент работает в режиме DPI: `qulogi -split 0`, где 0 — автоподбор точки разрыва после SNI.

### Приложение

```bash
git clone https://github.com/mel0k1/Qulogi.git
cd Qulogi/app
flutter create . --project-name qulogi --platforms android,windows
flutter pub get
flutter run
```

На вкладке «Настройки» укажите адрес сервера и ключ, затем нажмите кнопку на экране «Соединение». На десктопе приложение запускает бинарник `qulogi` из PATH.

## Сборка из исходников

```bash
go build ./cmd/qulogi ./cmd/qulogid
```

Готовые бинарники и APK собирает CI во вкладке Actions.

## Безопасность

- Ключ выводится из PSK через HKDF-SHA256 со свежими солениями на каждое соединение; соления никогда не повторяются.
- Каждый кадр шифруется AES-256-GCM со своим nonce, счётчик кадра входит в AAD — повтор и подмена отсекаются.
- Неверный PSK не раскрывает ничего: соединение молча закрывается на первом кадре.
- Журнал по умолчанию выключен; флаг `-v` показывает только события соединений, без содержимого трафика.
